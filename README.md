# CGCC-System: Google Login PHP Integration

This project integrates Google OAuth 2.0 Login using PHP, Composer, and the Google API Client. Follow the steps below to set it up properly on your local development machine.

---

## 🚀 Prerequisites

- PHP 7.4 or higher
- MySQL or MariaDB
- Composer (dependency manager for PHP)
- Apache (or a local server like XAMPP, MAMP, WAMP, or Laravel Valet)

---

## 🛠 Installation & Setup

### 1️⃣ Clone the Repository

>> go to xampp/htdocs
>> open in terminal
>> run this command 
git clone https://github.com/your-org/cgcc-system.git
cd cgcc-system

### 2️⃣ Install Composer Dependencies

If Composer is not installed on your machine:

- Download and install it from [https://getcomposer.org/](https://getcomposer.org/)
- Or run this command in the terminal (macOS/Linux):


## Run in terminal
### composer install
